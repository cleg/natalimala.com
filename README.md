# Natali Mala website

A static website with a dependency-free Python build script.

## Build

Requires Python 3 and macOS (`qlmanage` and `sips`, included with macOS).
No npm packages or third-party Python packages are needed.

```sh
python3 build.py
```

Publish the **contents of `dist/`** to https://natalimala.com/.

The build:

- copies HTML, CSS, JavaScript, both portrait sizes, SVG favicon and Open Graph image;
- serves `photo-mobile.jpg` (441×589) up to 720px viewport width and the original portrait above it;
- downloads DM Sans (400, 500, 600, 700) and Prata with the language subsets provided by Google Fonts;
- rewrites font URLs to local files and removes Google Fonts links from the output HTML;
- generates 32×32 and 180×180 PNG icons from `favicon.svg` using macOS tools;
- updates the output privacy note to reflect locally hosted fonts.

Fonts are cached in `.cache/fonts/`. The first build requires internet access;
subsequent builds can reuse the cache. Delete `.cache/fonts/` to refresh fonts.
A failed build preserves the existing `dist/` folder.

Edit source files in the project root, not generated files in `dist/`.
The existing `og-image.png` is copied as-is, not regenerated by the build.
PNG icons in the project root are development previews; release icons are
regenerated in `dist/` from `favicon.svg`.

## Local preview

```sh
python3 -m http.server 8000 --directory dist
```

Open http://localhost:8000/.

## GitHub Pages

Pushes to `main` run `.github/workflows/pages.yml`: build on macOS, then
publish only `dist/` through GitHub Pages. Source files remain at the repository
root; generated output and font caches are not committed.

In repository Settings → Pages, select GitHub Actions as the publishing source.
Until DNS is ready, use https://cleg.github.io/natalimala.com/.
The canonical and Open Graph URLs intentionally target the final domain.

When DNS becomes available, set the Pages custom domain to `natalimala.com`
before pointing DNS at GitHub Pages, then enable Enforce HTTPS when available.
For an Actions deployment, a `CNAME` file is not required. Domain email is
configured separately with a mail provider, not GitHub Pages.

To regenerate the mobile portrait after replacing `photo.jpg`:

```sh
sips -Z 589 -s formatOptions 78 photo.jpg --out photo-mobile.jpg
```
